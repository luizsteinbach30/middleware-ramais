Config padrão

Valores compartilhados por todos os telefones do ambiente. O servidor SIP é definido por linha na planilha.

SIP

O servidor SIP é informado por linha na coluna Servidor SIP da planilha — uma config aqui seria redundante.

Credencial atual do aparelho (usada para login)

Usuário e senha que os aparelhos do ambiente já têm hoje. O sistema usa isso para logar na web GUI e fazer upload do XML. Não vai no XML. Default de fábrica: admin / admin.

Nova credencial (opcional — vai no XML)

Se preenchidos, esses valores substituem a credencial admin do aparelho na próxima aplicação. Deixe vazio para não mexer na senha web. ⚠ Se mudar, lembre de atualizar a “credencial atual” acima na próxima vez, senão o sistema perde o acesso.

Validação antes do envio

Antes de enviar a config para cada aparelho, o sistema envia um ICMP ping para o IP. Se o aparelho não responde, a linha é marcada como erro e nada é enviado (proteção contra configurar o IP errado por engano). Recomendado ativar.
⚠ Algumas redes corporativas bloqueiam ICMP — nesse caso, desative aqui senão todas as linhas vão falhar.

Após aplicar e o telefone reiniciar, o sistema pode consultar o USCall para confirmar se o ramal registrou no PBX. Em lote, faz uma única consulta cobrindo todos os ramais (sem martelar o USCall). Requer USCall configurado em Configurações.

Avançadas (apenas modelos Intelbras)

Senhas que protegem o menu do telefone e o bloqueio de teclado. Default Intelbras é 123.

Function Keys (teclas programáveis)

Cada tecla vai para todos os telefones do ambiente. Quando “valor vem da planilha” está marcado, cada telefone usa o número informado na coluna correspondente da sua linha.
