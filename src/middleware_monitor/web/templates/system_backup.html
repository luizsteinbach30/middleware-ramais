Restauração agendada

O banco será substituído por — na próxima inicialização do middleware. Até lá nada muda: o sistema segue rodando com o banco atual. O banco substituído é guardado como pre-restore-*.db.

Exportar configuração

Gera um arquivo .mwrbak para importar em outra instalação. Ele carrega token do USCall, senha do broker e senha SIP de cada ramal — por isso é cifrado com a passphrase abaixo. Sem ela não há como abrir o arquivo.
